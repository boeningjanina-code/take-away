# Take away

Meine Mitnehmliste: für jedes Event aufschreiben, was mit muss, und beim Packen abhaken.

## Online stellen (GitHub Pages)
1. Alle Dateien in ein Repository hochladen (`index.html` muss ganz oben liegen).
2. Settings → Pages → Branch `main`, Ordner `/ (root)` → Save.
3. Nach ein, zwei Minuten läuft die App unter `https://<name>.github.io/<repo>/`.

## Aufs Handy
- iPhone: Link in Safari öffnen → Teilen → „Zum Home-Bildschirm“.
- Android: Link in Chrome öffnen → Menü → „App installieren“.

Die Listen werden im Browser auf dem Gerät gespeichert.
